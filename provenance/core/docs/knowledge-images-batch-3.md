# Knowledge images — batch 3

100 existing equipment pages receive reviewed, locally hosted photographs. Coverage rises from 149 to **249 of 911 enriched pages**, leaving **662** without images. Together, batches 2 and 3 add 200 images: 100 ingredient pages and 100 equipment pages. No recipe, canonical identity, relationship, resource or knowledge prose was changed.

The new equipment images total **9,304,362 bytes (8.9 MiB)**; both batches total **20,598,189 bytes (19.6 MiB)**. Images are full-frame progressive JPEGs at quality 82, at most 960 pixels on the longest edge, without upscaling and below 350 KB each. Embedded metadata is removed; attribution remains in the page, [asset credits](../assets/references/ATTRIBUTION.md) and [machine-readable ledger](knowledge-images-batch-3.json). File-specific Commons metadata records creator, original file, source page and exact licence version/port. Only public-domain, CC0, CC BY and CC BY-SA images were selected.

## Selection and limitations

All 100 images were visually inspected. Wikipedia lead-image discovery was only a starting point; the Commons file record supplies licensing and each image was checked for the actual equipment. Rejected candidates included an unrelated herb/seed grinder for coffee, a champagne flute for a coupe, laboratory sieves, ordinary scissors for kitchen shears, a dish of pasta for a pasta machine, and a blender search result showing only a jug and drinks. An ice-cube-tray image lacking creator metadata was replaced with an attributed photograph.

Some photographs show tools in use rather than isolated product views: a rolling pin working flatbread, a mallet flattening pork, a fillet knife separating fish, a wok cooking noodles, and a ricer pressing potato. Captions state those contexts. The springform image illustrates its latch; the commercial ice-cream machine illustrates one scale of equipment; neither is presented as every version of the item. Brand markings visible within photographs are incidental, not endorsements. No additional cropping or artwork generation was used.

## Preservation and validation

Tests pin all 100 new images and their metadata, compare the complete prior enrichment registry after removing only these additions, and check canonical files, resources and all previous image bytes. Earlier batch tests retain their original historical counts and hashes through explicit later-batch projections.

- Core: type checking, build, 1,389 tests, documentation checks (31 documents) and quality audit passed. The existing 10 sample quality findings remain unchanged.
- Corpus: 395 tests and all 490 recipe parses passed; Corpus sources unchanged.
- Site: type checking, 128 tests, build and validation passed: 1,667 pages, 2,073 files, 66,711 internal links and 2,450 fragments.
- Clean-source audit passed: 1,492 files, 969 knowledge entries and 14 samples. Unrelated user files and ignored archives were excluded and left untouched.
- Ordinary localhost HTTP audit passed: all 1,667 pages matched built HTML; all 100 equipment image URLs returned 200, image/jpeg and exact saved SHA-256 bytes, with captions and attribution verified. One transient connection reset was retried without relaxing any assertion.
- All selected images were visually reviewed. An in-app browser spot-check of mortar and pestle confirmed the image, caption and expanded credit/licence disclosure. This is not a full browser suite or mobile/theme matrix.
- Git whitespace checks passed. Core and Site changes are locally committed on codex/knowledge-images-batch-3; no merge, push or deployment.
